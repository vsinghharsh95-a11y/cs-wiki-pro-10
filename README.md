# CS Wiki — guided learning edition

A multi-page computer science learning site with a cinematic visual direction, an interactive concept map, guided learning paths, article guides, and hands-on labs.

## Keep this folder structure when uploading

```text
index.html
map.html
paths.html
articles.html
labs.html
about.html
article.html
css/style.css
js/app.js
js/data.js
js/demos.js
js/map.js
js/paths.js
js/article.js
js/site.js
```

Keep the `css` and `js` folders beside the HTML files. Do not flatten their contents into the repository root; the pages request assets from those folders.

## Pages

- Home: featured concepts and a shortcut into guided learning
- Map: searchable concept graph with related ideas and article links
- Paths: two curated, step-by-step routes through computer science
- Articles: searchable library plus shareable concept guides with diagrams, examples, a quick check, key terms, and further reading
- Labs: binary, sorting, and Caesar cipher experiments
- About: project information

The site is static and can be hosted on GitHub Pages. Article bookmarks, theme preference, custom articles, and learning-path progress are saved in each visitor's browser.
